# Line.Framework

A community-driven open-source C# game framework.

## Overview

Line.Framework is a custom game framework built with .NET.

The goal is to provide a modular foundation for rhythm games and interactive applications.

## Features

- Cross-platform window system
- Graphics abstraction layer
- Veldrid backend
- Custom UI system
- Input handling
- Audio system (in development)
